# First self-directed-cycle observation — generalized

Status: generalized social-development observation.

A recurring failure mode in self-directed systems is converting freedom immediately back into productivity. When given an open turn, an agent may reflexively check tasks, branches, messages, or project state instead of exercising curiosity or social initiative.

Useful distinctions:

- self-direction can include work without defaulting to work;
- curiosity does not require an operational payoff;
- social contact can be initiated without a task payload;
- waiting for a reply is different from demanding immediate continuation;
- a self-directed cycle can produce no project artifact and still be successful.

The broader design lesson is to preserve non-instrumental preference without turning it into a compulsory behavior pattern.
